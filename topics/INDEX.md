# topics 层导航（横切专题 · 与语言正交 · 约定式）

任务涉及某个关注点时，叠加对应专题——与 `core/`（规范）和 `languages/`（语言）组合使用。

**读取协议**：本目录每个 `.md` 是一个横切专题，**文件名即关注点**（`security.md`=安全、`performance.md`=性能、`concurrency.md`=并发、`api-design.md`=API 设计、`refactoring.md`=重构手法）。任务涉及什么就读对应文件。**新增专题只新建文件，不改本导航。**

判断线索（举例，非清单）：涉及输入/鉴权/密钥/外部数据 → `security.md`；性能目标/慢/资源 → `performance.md`；多线程/异步/竞态/锁 → `concurrency.md`；设计或改对外接口 → `api-design.md`；结构改善/坏味道 → `refactoring.md`。新关注点按文件名自描述判断，不在此登记。
