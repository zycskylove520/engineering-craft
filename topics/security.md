# 安全工程（横切专题）

## 1. 输入即不可信
- 所有外部输入（用户、网络、文件、环境变量、第三方响应）在边界校验，白名单优于黑名单。
- 长度/类型/范围/格式全部限制；失败显式拒绝，不静默修正。

## 2. 常见注入
- SQL 用参数化查询/ ORM，不拼字符串。
- 命令执行避免 shell 拼接；路径操作防目录穿越（规范化 + 白名单根）。
- XSS/模板注入按上下文转义；反序列化只用可信源。

## 3. 密钥与敏感信息
- 密钥不硬编码、不入日志、不进仓库；用环境变量/密钥管理服务。
- 日志脱敏（密码/令牌/个人信息）；错误信息不泄露内部细节。

## 4. 权限与最小授权
- 默认最小权限；每个操作问"是否有必要"；越权要显式拒绝。
- 认证与授权分离；会话/令牌有过期与撤销。

## 5. 依赖安全
- 依赖版本锁定；关注已知漏洞（audit/SCA）；评估许可证；减少不必要的依赖面。

## 6. 交付前
扫一遍 diff 里的密钥、隐私、注入点；把安全相关的假设写成测试。
