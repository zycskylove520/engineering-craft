# 性能工程（横切专题）

## 1. 度量先行
- 先测后优化：没有 profile 数据不优化，凭感觉优化是浪费。
- 定义指标与基线（延迟 P50/P95、吞吐、内存、CPU），改动前后对比。

## 2. 找瓶颈
- 从最耗时/最频繁路径入手（Amdahl）；区分 IO 密集与 CPU 密集。
- 用采样剖析而非逐行猜；关注算法复杂度高于微优化。

## 3. 常用手段
- 缓存：明确失效策略与命中率；避免缓存不一致。
- 批量与预取：减少往返；分页/流式处理大数据。
- 数据结构与算法：选对结构比调参有效；避免重复计算。

## 4. 陷阱
- 过早优化、优化非热点、牺牲正确性换性能、缓存无失效、内存泄漏。
- 并发不等于更快（锁竞争/上下文切换）。

## 5. 验证
性能优化必须带基准数据与正确性验证；不能让测试变慢到不可接受而不说明。
